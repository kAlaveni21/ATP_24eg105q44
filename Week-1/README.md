# 📘 Week 1 – JavaScript Fundamentals

## Description

This folder contains Week 1 JavaScript assignments covering basic programming concepts such as arrays, functions, loops, conditional statements, and array operations.

## 🎯 Objectives

- Learn JavaScript fundamentals
- Practice array operations (insert, delete, update, search)
- Understand functions and conditional statements
- Improve problem-solving skills using JavaScript

## 🛠️ Technologies Used

- JavaScript (ES6+)
- Node.js
- VS Code

## 📁 Folder Structure

```
Week-1/
│
├── array.js               # Insert, delete, update operations on employee array
├── arraySum.js            # Sum of array elements using a function
├── biggestThree.js        # Biggest among three numbers using a function
├── bigofThree.js          # Biggest among three numbers using conditional statements
├── bigofTwo.js            # Biggest among two numbers using if-else
├── Search.js              # Search an element in an array and return its index
├── smallestofArray.js     # Find the smallest element in an array
├── sumofArray.js          # Sum of array elements
└── README.md
```

## 📋 Programs Included

| File Name | Description |
|-----------|-------------|
| `array.js` | Performs insert, delete, and update operations on employee array objects |
| `arraySum.js` | Finds the sum of array elements using a function |
| `biggestThree.js` | Finds the biggest among three numbers using a function |
| `bigofThree.js` | Finds the biggest among three numbers using conditional statements |
| `bigofTwo.js` | Finds the biggest among two numbers using if-else |
| `Search.js` | Searches an element in an array and returns its index |
| `smallestofArray.js` | Finds the smallest element in an array |
| `sumofArray.js` | Computes the sum of all elements in an array |

## ▶️ How to Run

```bash
node <filename>.js
# Example:
node array.js
```
