# 📒 Week 5 – Frontend Development: HTML Tables, Tailwind CSS & React

## Description

This folder covers frontend development concepts including HTML tables with CSS styling, a Tailwind CSS project, and a React application built with Vite. It marks the transition from backend to UI development.

## 🎯 Objectives

- Build structured HTML tables with styling
- Use Tailwind CSS utility classes for rapid UI development
- Set up a React application using Vite
- Understand React components, JSX, and project structure

## 🛠️ Technologies Used

- HTML5 / CSS3
- Tailwind CSS
- React.js
- Vite
- Node.js / npm

## 📁 Folder Structure

```
Week-5/
│

│   ├── UsersTable.html        # Styled users data table

│   │   ├── App.jsx            # Root component
│   │   ├── main.jsx           # App entry point
│   │   └── App.css            # App styles
│   ├── public/                # Static assets

│
└── README.md
```

## 📋 Projects Included

| Project | Description |
|---------|-------------|
| `Tables/` | HTML tables with CSS styling — users, subjects, and title data |
| `TailWind-Project/` | UI project built with Tailwind CSS utility classes |
| `react-app-1/` | React application scaffolded with Vite, including reusable components |

## ▶️ How to Run

```bash
# Open HTML table files directly in a browser (no server needed)

# Tailwind Project
cd TailWind-Project
npm install
npm run dev

# React App
cd react-app-1
npm install
npm run dev
# Open: http://localhost:5173
```
