# 📗 Week 2 – Advanced JavaScript

## Description

This folder contains Week 2 JavaScript assignments that build on fundamentals and introduce advanced concepts such as ES6 modules, spread/rest operators, object manipulation, real-world simulations, and task management with validation.

## 🎯 Objectives

- Understand and apply ES6 Modules (import/export)
- Practice Spread and Rest operators for arrays and objects
- Build real-world simulation programs (shopping, payroll, streaming, etc.)
- Implement task management with validation logic

## 🛠️ Technologies Used

- JavaScript (ES6+)
- Node.js
- VS Code

## 📋 Programs Included

| File / Folder | Description |
|---------------|-------------|
| `BankTransaction.js` | Simulates bank deposit, withdrawal, and balance tracking |
| `DailyTemperature.js` | Records and analyses daily temperature data |
| `LibraryBook.js` | Manages library book records (add, borrow, return) |
| `StudentMarks.js` | Processes and calculates student marks |
| `countdownSimulator.js` | Simulates a countdown timer using loops |
| `employeePayroll.js` | Calculates employee salaries and deductions |
| `movieStreaming.js` | Simulates a movie streaming service |
